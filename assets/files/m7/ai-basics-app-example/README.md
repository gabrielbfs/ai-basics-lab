# Trail Club unit economics

A one-page calculator that shows whether a Trail Club member is worth what it costs to win them. Change the price, gross margin, monthly churn or acquisition cost, and the lifetime value (LTV), LTV/CAC and payback update.

**Example app for the AI Basics Lab (MIT Sloan), Module 7.** Ridgeway Trail Co. is a fictional company and every figure is made up. Not financial advice.

## Open it

Double-click `index.html`. It runs in any browser, with nothing to install.

## Check it

Open `tests.html` to run the acceptance checks from `docs/spec.md`.

## What's here

| File | What it does |
| --- | --- |
| `index.html` | The page: inputs, results and messages |
| `style.css` | The look, including dark mode and phone layout |
| `app.js` | The calculations (`calculate()`) and the code that updates the page |
| `tests.html` | Acceptance checks for the calculations |
| `CLAUDE.md` | Standing instructions for Claude Code in this folder |
| `docs/spec.md` | The build spec (Module 5) |
| `docs/prototype.html` | The prototype it grew from (Module 4) |
